# Alt Mobility – Assignment

This repository contains my submission for the **Data Analyst Intern Assignment** at **Alt Mobility**. It includes SQL-based analysis, customer retention visualization, and a summary of findings based on two datasets: `customer_orders.csv` and `payments.csv`.

## ✅ Task Overview

### - Task 1: Order and Sales Analysis
- Analyzed order statuses and revenue trends.
- Key metrics include total revenue, monthly sales, and order completion rates.

### - Task 2: Customer Analysis
- Identified repeat customers and ordering patterns.
- Segmented customers based on frequency of purchase.

### - Task 3: Payment Status Analysis
- Explored payment success vs failure rates.
- Monitored payment issues across different periods.

### - Task 4: Order Details Report
- Combined order and payment data into a unified report using SQL joins.
- Provided detailed records for operational insights.

### - Task 5: Customer Retention Visualization
- Built a **cohort retention heatmap** to visualize repeat purchase behavior.
- Showed how many customers from each cohort returned in subsequent months.
